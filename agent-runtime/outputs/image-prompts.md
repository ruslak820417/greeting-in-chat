## Thumbnail Prompts

### Prompt 1 (Main Thumbnail)
```
A dark terminal screen split into 6 glowing panels, each panel highlighted
with a different neon color (yellow, blue, green, purple, red, orange).
Thin luminous connection lines between panels showing communication flow.
Text overlay "6 AI AGENTS" in bold white. Cyberpunk aesthetic, dark background
#1a1b26, high contrast, 16:9 aspect ratio, photorealistic terminal UI.
```

### Prompt 2 (Alternative)

Hub-and-spoke diagram with a central golden node labeled "LEAD" connected to

Dark gradient background, glowing edges, tech-futuristic style, 16:9.

## Scene Image Prompts

### Scene: Single Agent vs Team (Сцена 2)
```
Split image. Left side: single robot at a desk, working alone, dim lighting,
monochrome blue. Right side: 6 robots at connected workstations, each glowing
a different color, actively passing documents between them, vibrant lighting.
Clean minimalist illustration style, dark background, 16:9.
```

### Scene: Architecture Diagram (Сцена 3)
```
Futuristic holographic organizational chart floating in dark space.
Central node "SHOWRUNNER" in gold, connected by luminous lines to 5 specialist
nodes arranged in a semicircle below. Each node pulses with its signature color
and displays a role icon. Data particles flow along the connection lines.
Sci-fi UI aesthetic, transparent panels, 16:9.
```

### Scene: Parallel Execution (Сцена 4)
```
Top-down view of 6 parallel racing lanes on a dark track. Each lane glows
a different neon color. In each lane, a cursor/pointer races forward at
different speeds, leaving a glowing trail. Some lanes have checkpoint markers
where they sync. Cyberpunk racing aesthetic, motion blur, 16:9.
```

### Scene: Handoff Moment (Сцена 4)
```
Two glowing hands passing a luminous document in dark space. Left hand glows
blue (researcher), right hand glows green (fact-checker). The document has
a faint checkmark pattern. Particle effects at the transfer point.
Minimalist, dark background, dramatic lighting, 16:9.
```

### Scene: Results Showcase (Сцена 5)
```
A dark desktop surface with 6 glowing document cards arranged in a fan layout.
Each card has a colored header matching an agent's color and shows faint text
lines. A golden stamp "COMPLETE" overlays the arrangement. Subtle light rays
emanate from the documents. Clean, professional, dark background, 16:9.
```

### Scene: Before/After (Сцена 5)
```
Split image with a dividing line. Left: empty dark folder icon, cobwebs,
dim lighting, text "BEFORE". Right: the same folder overflowing with colorful
glowing documents, each a different color, text "AFTER". Dramatic contrast,
clean design, dark background, 16:9.
```

### Scene: Future Vision (Сцена 6)
```
Silhouette of one person standing before a massive holographic display showing
dozens of AI agent nodes working in a network. The person conducts them like
an orchestra conductor. Nodes pulse with various colors, data streams flow
between them. Epic scale, cinematic lighting, sci-fi atmosphere, 16:9.
```
