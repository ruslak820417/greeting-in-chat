<objective>
Harden the SDP delivery pipeline and add end-to-end diagnostic logging for cold start calls. Ensure TURN servers are included in both VoIP push payload AND get-call-state response. Add duplicate offer suppression in MessagingService when the coordinator already handled the call. Add structured timing logs that make debugging cold start failures straightforward.

Purpose: Even with the coordinator refactor (plan 01), SDP delivery can fail silently if VoIP push doesn't include the full offer or if TURN servers are missing. The server must include all required data in both delivery paths. Additionally, when the coordinator handles the call via PATH A (VoIP push), the pending queue still delivers the same offer, triggering duplicate incoming-call events that the coordinator must suppress.

Output: Server-side fixes for data completeness + client-side duplicate suppression + diagnostic logging.
</objective>
